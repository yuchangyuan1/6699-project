# Adaptive Preconditioned Dynamics, Solution Geometry, and Generalization

Code, results, and report for the matched-seed Adam-vs-SGD study on
Fashion-MNIST described in `report/revised_report.tex`.

## Directory Layout

```
.
├── part1/                # Part I: early-stage convergence (loss thresholds)
│   ├── configs/          # YAML configs for the three experiments
│   ├── scripts/          # CLI entry points
│   ├── src/              # training / aggregation modules
│   └── outputs/          # per-seed CSVs and aggregated CSVs
├── part2_part3/          # Part II / Part III: solution geometry + generalization
│   ├── *.py              # training, evaluation, plotting scripts
│   └── results_part2/    # JSON results, final-epoch state_dicts, flat-param .npy
├── report/
│   ├── revised_report.tex   # current report source
│   ├── revised_report.pdf   # compiled PDF
│   └── figures/             # figures referenced by the LaTeX source
│       ├── part2_geometry/
│       └── part3_generalization/
└── README.md             # this file
```

The Fashion-MNIST cache and large per-epoch checkpoints are not committed;
see Reproduction below.

## Report

The compiled report is `report/revised_report.pdf`. The source is
`report/revised_report.tex` and pulls every figure from `report/figures/`.

## Reproduction

### Dependencies

Python 3.10+, PyTorch 2.x, torchvision, numpy, pandas, matplotlib, pyyaml,
tqdm. Install with:

```bash
pip install -r part1/requirements.txt
```

The Fashion-MNIST dataset is downloaded automatically on first run by
`torchvision`.

### Part I: convergence thresholds

```bash
cd part1
python scripts/run_lr_search.py  --config configs/experiment_c_lr_search.yaml
python scripts/run_multi_seed.py --config configs/experiment_a_mlp.yaml
python scripts/run_multi_seed.py --config configs/experiment_b_cnn.yaml
python scripts/summarize_results.py \
    --configs configs/experiment_a_mlp.yaml configs/experiment_b_cnn.yaml
```

Threshold-crossing data for Table~\ref{tab:q1_thresholds} of the report ends
up in `outputs/exp_*/aggregated_thresholds.csv`.

### Part II / Part III: geometry, basin, function, representation

```bash
cd part2_part3
python train_part2.py            # 20 runs (2 archs * 2 opts * 5 seeds)
python run_pipeline.py           # all evaluation scripts + plotting
```

`train_part2.py` writes per-run JSONs and state_dicts under
`results_part2/`, and per-epoch checkpoints under
`results_part2/checkpoints/` (needed by `loss_matched_geometry.py`).
`run_pipeline.py` runs:

* `perturbation_flatness.py`, `mode_connectivity.py`, `function_space.py`,
  `representation_cka.py`, `loss_matched_geometry.py`,
  `baseline_same_optimizer.py`
* `plot_part2.py`, `plot_part3.py`, `plot_pipeline_figures.py` to write
  figures into `../report/figures/part{2_geometry,3_generalization}/`

To re-run only one analysis:

```bash
python run_pipeline.py --only mode_connectivity.py
```

### Numerical values printed in tables

`python part2_part3/dump_numbers.py` reads every JSON under
`results_part2/` and prints the mean ± std values that appear in the
report tables.

## What is shipped

* `part1/outputs/`: per-seed CSVs, aggregated CSVs, summary markdown.
* `part2_part3/results_part2/`: per-run JSONs, final-epoch state_dicts
  (`*_state.pt`), flat parameter vectors (`*_params.npy`), and the six
  evaluation JSONs (`mode_connectivity`, `function_space`,
  `representation_cka`, `perturbation_flatness`, `loss_matched_geometry`,
  `baseline_same_optimizer`).
* `report/figures/`: every PNG referenced by the LaTeX source.

The per-epoch checkpoint directory (`results_part2/checkpoints/`) and the
Fashion-MNIST cache are excluded; both are regenerated by
`train_part2.py` on first run. `loss_matched_geometry.py` requires those
per-epoch checkpoints to recompute the loss-matched control, but its JSON
output is already shipped, so re-running is only needed if you change
training hyperparameters.
